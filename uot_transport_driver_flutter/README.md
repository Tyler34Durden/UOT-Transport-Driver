# UOT Transport Driver

Flutter mobile app for UOT transport drivers.

## Tech Stack

- Flutter
- Dart

## Requirements

- Flutter SDK
- Dart SDK (bundled with Flutter)
- Android Studio or Xcode (for device emulators and platform builds)

## Setup

```bash
flutter pub get
```

## Run

```bash
flutter run
```

## Project Structure

- lib/auth_feature/ - Authentication feature module
- lib/home_feature/ - Home feature module
- lib/core/ - Shared utilities and services
- assets/ - Fonts, icons, and images

## Notes

- If the app depends on external services, add required keys/configs in the
  platform-specific files before running.
